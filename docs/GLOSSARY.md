# 『福嶋晴菜の はるまとぺーじ』專屬用語與打招呼演變詞庫

本文檔記錄節目專屬問候語、聽眾稱呼、單元名稱與方案術語之演變脈絡與標準化對照。

---

## 1. 核心問候語演變脈絡（Greeting Evolution）

### 演變公式
> **こんばんわ（晚安） ＋ はるまとぺーじ（節目標題） ＝ こんまとぺ（Konmatope）**

### 歷史軌跡
1. **EP01（開播初見）**：
   - 福嶋晴菜首次個人廣播，向聽眾表示想在後續集數與大家一同決定節目專屬的問候語與聽眾稱呼。
2. **EP03（熱烈發想）**：
   - 聽眾來信提出各種點子，其中聽眾「りんご」結合翻開書頁的擬聲詞提議「ペラッパ（Perappa）」，福嶋大讚可愛，並表示持續向大家募集好點子。
3. **EP04（神來一筆）**：
   - 聽眾「ドラル（Doral）」在信件開頭自然融入「こんまとぺ」作為招呼語，深深印在福嶋腦海中。
4. **EP05（正式定案）**：
   - **聽眾專屬稱呼**：拍板定案為「**しおり**」（書籤，象徵每封信像書籤一樣陪伴節目每頁）。
   - **官方專屬問候語**：正式選定為「**こんまとぺ**」。
   - **決定理由**：
     - 福嶋奉行「Simple is best」，「こんまとぺ」結合了晚間廣播標準問候「こんばんわ」與節目標題「はるまとぺーじ」。
     - 發音順口好唸（類似 こんばんは / こんにちは），且包含節目核心詞彙「まとぺ」。
     - 具備高度時間彈性：早晨可變形為「**おはまとぺ**」，夜晚可變形為「**ばんまとぺ**」，但「こんまとぺ」任何時段皆通用。
5. **EP06（老友相聚與命名回顧）**：
   - 向嘉賓藤本侑里介紹第 5 回定案的「こんまとぺ」。
   - 同時回顧當初節目名稱『はるまとぺーじ』是由藤本侑里提議（源於福嶋說自己喜歡「オノマトペ（擬聲詞）」）。
6. **EP07~EP10（全面通用）**：
   - 聽眾投稿全面自然使用「こんまとぺ」。
   - EP08 聽眾與嘉賓根本優奈亦自然延伸使用「**おはこんまとぺ**」。

## 4. 常客書籤名

同一位聽眾各回寫法要一致。字幕常把名字聽錯，已知的誤聽也收在 `content/glossary.json`，新的一回先跑 `npm run glossary:dry-run -- --input content/epNN.ja.vtt`。

| 書籤名 | 出現的回 | 字幕常見誤聽與備註 |
| :--- | :--- | :--- |
| たけのこの山 | 1、3、5、6、8、10、11、12 | たのこの山、竹のこの山、竹中の山。字幕多半聽成たのこの山，但第 3 回福嶋慢慢唸是たけのこの山，第 10 回佐藤叫たけのこの山っち |
| 君にあげるキムチなんてない | 2、4、5、6、8、11 | 君にあげる気持ちなんてない。第 8 回根本記成「キムチなんてやらないぞ」；名字前的「千理」「しれでも」是しおりネーム的誤聽 |
| 木さぎいつか | 2、3、5、9、10、11 | 木さぎ塚、セラぎ塚。第 3 回提議聽眾名字「福耳さん」的就是這位 |
