字幕人名標外框改善方案

問題：標籤的邊框就是字色，福嶋晴菜的淡紫落在片頭那種薰衣草背景上，邊框跟背景融在一起，標籤輪廓不見。下面五種只改標籤的外框，字號、間距、位置都跟現在站上一樣。用上方的色塊切背景，看哪一種在哪種畫面會失效。
