邊聽邊標記

  • 不用切模式，影片照播。聽到標錯，按鍵標記正在播的那一列：[ 對調起點、] 對調終點、S 單句對調、? 待查（不確定是誰，之後再看）。
  • 反應慢半拍很正常：清單裡每個時間兩邊的箭頭可以往前往後挪一列。點時間本身跳回那裡重聽。
  • 起點和終點按時間配對。少了一邊、或連按兩個起點，清單會標紅，不會被套用。
  • 全部套用：所有配好的段落和單句一次對調，改動出現在下面的「寫回」預覽，還沒存檔，可以復原。待查不會自動套用，點它的「去改」會切到編輯模式並選好那一列。

怎麼操作（編輯模式）

  • 聆聽模式：跟現在的網站一樣，點文字播放器跳到那一列，沒有勾選框也沒有調整區。
  • 切到編輯（右上角開關，或按 E）：影片自動暫停，正在播的那一列先幫你選起來。下面幾項都只在編輯模式有。
  • 切回聆聽：影片接著播。還沒寫回的改動會保留，右上角顯示「未存 N 列」，點它回到編輯模式。
  • 選一段：編輯模式下點 A 列，按住 Shift 再點 B 列，A～B 全部選起來。點整列任何地方都可以，不用瞄準小方框。
  • 點兩端（調整區「選範圍」的按鈕，或按 R）：不用按 Shift。按一下，再點範圍的第一列，那列會標「起點」；接著點另一端，中間全部選起來，然後自動結束。上下哪一端先點都可以，按 Esc 取消。
  • 勾左邊的方框：只加入或拿掉那一列，其他已選的不動，用來挑不相連的幾列。也可以在調整區打時間選。
  • 點時間標籤：編輯模式下要重聽某一列，點它的時間。
  • 點人名標籤：單列切換，依序是 福嶋 → 佐藤 → 兩人同時 → 工作人員。
  • 對調：選到的列福嶋和佐藤互換，「兩人同時」和「工作人員」不動。快捷鍵 S。
  • 改過的列左邊有橘色線，人名旁邊劃掉的是檔案裡原本的標籤。按「寫回」才會存檔。

這個工具改不了的

  • 一列裡其實有兩個人在講：要拆列，換標籤沒用。先記下時間，另外改。
