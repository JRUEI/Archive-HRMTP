merge 之後站上會變的三件事

改動集中在 src/components/Header.tsx，外加 HomeEpisodeList.tsx 的一行。

  • 左上角

    紫色藥丸 → 漸層站名

    改成純文字，福嶋晴菜の 用基本色，「はるまとぺーじ」 沿用首頁大標同一組紫→綠漸層。顏色全走 brand-purple / brand-green 變數，沒有寫死色碼。視窗小於 640px 時只留後半段。

  • 頁首

    頁首往內收，對齊集數列表

    列表寬度完全不動。改的是頁首：外層維持 max-w-6xl px-6，裡面再包一層 max-w-4xl mx-auto，和 HomeEpisodeList 的結構一模一樣。站名左緣貼齊日期欄，圖標右緣貼齊卡片右緣。

  • 取捨

    「影片清單」四個字消失

    播放清單按鈕變成純圓形圖標，和你給的參考圖一致。title 與 aria-label 都保留，滑過去有提示、輔助工具讀得到，但辨識度確實下降。想留字的話講一聲。

還沒處理的

不在這次改動範圍內，列出來讓你決定要不要一起處理。

  • 重複

    首頁大標和頁首站名長得一樣

    src/app/page.tsx 仍然在頁首正下方渲染同一串文字，所以首頁上這行字連續出現兩次 —— 上面兩個模擬視窗裡都看得到。刪掉大約 8 行的事，但超出你原本要求的範圍，所以我沒動。

    npm run lint 在 main 上本來就是紅的

    TranscriptMode.tsx 有三個 no-explicit-any 錯誤，跟這次改動無關，但連帶讓 npm run verify 過不了。npm run build 本身正常，Pages 部署不受影響。
